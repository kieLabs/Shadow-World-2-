# SHADOW WORLD 2 — 40 Chapters (GamerKie Edition)

A high-lethality, monochrome silhouette platformer inspired by Playdead's *LIMBO*, featuring 40 continuous chapters across 4 atmospheric acts, procedural 2D Inverse Kinematics (IK) Giant Spiders, draggable bear traps, brainworm parasites, electrified HOTEL signs, turrets, and gravity inversion.

## GitHub Pages Deployment
1. Upload all files inside `shadow-world-2/` to the root of your GitHub repository (`shadow-world-2`).
2. Go to **Settings > Pages > Build and deployment**, set **Source** to `Deploy from a branch`, select `main` and `/ (root)`, and click **Save**.
3. Your live game URL (`https://<your-username>.github.io/shadow-world-2/`) can be pasted directly into `blogger-embed.html`.
