# SHADOW WORLD 2 — 40 Chapters (GamerKie Edition)

A high-lethality, monochrome silhouette platformer inspired by Playdead's *LIMBO*, featuring 40 audited continuous chapters across 4 atmospheric acts, procedural 2D Inverse Kinematics (IK) Giant Spiders, draggable bear traps, solvable two-tier brainworm puzzles, electrified HOTEL signs, turrets, gravity inversion, and a Chapter 40 glass-shattering finale.

## GitHub Pages Deployment
1. Upload all files inside `shadow-world-2/` to the root of your GitHub repository (`shadow-world-2`).
2. Go to **Settings > Pages > Build and deployment**, set **Source** to `Deploy from a branch`, select `main` and `/ (root)`, and click **Save**.
3. Copy your live URL (`https://<your-username>.github.io/shadow-world-2/`) into `blogger-embed.html`.
